SOURCE PACKAGE - Dynamic Precision-Scalable Systolic Array using DFX
Project: 4x4 systolic matrix multiplier whose precision (int16 / int8 / int4) is swapped at run time by Dynamic Function eXchange (DFX).
Board: ZedBoard, Zynq-7000 xc7z020clg484-1.
Tool version: Vivado 2022.2 (project mode, DFX), Python 3 with NumPy for the reference model.
How to use: in Vivado Hardware Manager program bitstreams/t2/t2_full_int16.bit first, with probes file bitstreams/t2/t2_full_int16.ltx; then load any bitstreams/t2/t2_partial_*.bit (the probes file stays the same).
No .coe files: the design uses no memory initialisation files.
Update this note if files change. Each entry: path inside submission/ <- original location, then one line on what the file is.

=== verilog/rtl_t0  (T0: the int16 systolic array) ===
verilog/rtl_t0/array.v <- rtl/array.v
  4x4 output-stationary systolic array of pe cells (also reused unchanged by the T2 int16 module).
verilog/rtl_t0/controller.v <- rtl/controller.v
  Control state machine and staircase feed generator for the array (reused unchanged in T2).
verilog/rtl_t0/loader.v <- rtl/loader.v
  Converts the UART byte stream into matrices and reads results back, clamped to 32 bits (serial system).
verilog/rtl_t0/pe.v <- rtl/pe.v
  One processing element: int16 multiply, 48-bit accumulate, maps to one DSP slice (reused in T2 int16).
verilog/rtl_t0/top.v <- rtl/top.v
  T0 serial system top: UART in, loader, controller, array, UART out (verified in simulation).
verilog/rtl_t0/top_vio.v <- rtl/top_vio.v
  T0 board top: the array controlled over JTAG through a VIO debug core; the design run on silicon.
verilog/rtl_t0/uart_rx.v <- rtl/uart_rx.v
  8N1 UART receiver for the serial system.
verilog/rtl_t0/uart_tx.v <- rtl/uart_tx.v
  8N1 UART transmitter for the serial system.

=== verilog/rtl_t1  (T1: the DFX swap mechanism; three files reused by T2) ===
verilog/rtl_t1/dfx_decouple.v <- rtl/t1/dfx_decouple.v
  Registered decoupler: forces the swappable region's outputs to safe values during a swap (reused in T2, 45 bits).
verilog/rtl_t1/rst_sync.v <- rtl/t1/rst_sync.v
  Two-flop reset synchroniser for the active-high push button (reused in T2).
verilog/rtl_t1/top_dfx.v <- rtl/t1/top_dfx.v
  T1 static top: reset, uptime counter, decoupler, VIO and the reconfigurable partition U_RP.
verilog/rtl_t1/uptime.v <- rtl/t1/uptime.v
  Seconds counter and 1 Hz heartbeat that prove the static region keeps running (reused in T2).
verilog/rtl_t1/rm/rm_add.v <- rtl/t1/rm/rm_add.v
  T1 reconfigurable module: 16-bit adder, ID A1.
verilog/rtl_t1/rm/rm_mul.v <- rtl/t1/rm/rm_mul.v
  T1 reconfigurable module: 16-bit multiplier on one DSP slice, ID B2.

=== verilog/rtl_t2  (T2: precision variants behind one frozen interface) ===
verilog/rtl_t2/top_t2.v <- rtl/t2/top_t2.v
  T2 static top: controller, feed registers, start gate, done flag, decoupler, uptime, LEDs, VIO and U_RP.
verilog/rtl_t2/rm/rm_int16.v <- rtl/t2/rm/rm_int16.v
  int16 module (Verilog module rp_t2): T0 array on 16 DSP slices, 48-bit accumulators, result clamped to 32 bits, ID 16.
verilog/rtl_t2/rm/rm_int8.v <- rtl/t2/rm/rm_int8.v
  int8 module (module rp_t2): inputs clamped to 8 bits, LUT array, 18-bit accumulators, 0 DSP, ID 08.
verilog/rtl_t2/rm/rm_int4.v <- rtl/t2/rm/rm_int4.v
  int4 module (module rp_t2): inputs clamped to 4 bits, LUT array, 10-bit accumulators, 0 DSP, ID 04.
verilog/rtl_t2/rm/rm_common.v <- rtl/t2/rm/rm_common.v
  Shared submodules of the T2 modules: input clamp (lane_sat), result select and conversion (rm_readout), ID and LED badge (rm_badge).
verilog/rtl_t2/rm/array_lut.v <- rtl/t2/rm/array_lut.v
  4x4 array of pe_lut cells with the same layout as the T0 array (used by int8 and int4).
verilog/rtl_t2/rm/pe_lut.v <- rtl/t2/rm/pe_lut.v
  Processing element built in LUT fabric (use_dsp = "no"), parameterised for int8 and int4.
